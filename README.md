## 🕹️ The Arcade — Contribution Games

Three different generators race to eat the same contribution grid. Keep whichever wins.

### 🐍 Snake

<div align="center">
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/itsprathi/itsprathi/output/github-contribution-grid-snake-dark.svg" />
  <source media="(prefers-color-scheme: light)" srcset="https://raw.githubusercontent.com/itsprathi/itsprathi/output/github-contribution-grid-snake.svg" />
  <img alt="A snake eating my GitHub contribution graph" src="https://raw.githubusercontent.com/itsprathi/itsprathi/output/github-contribution-grid-snake.svg" />
</picture>
</div>

<details>
<summary><b>🔧 Set up the snake (one-time)</b></summary>
<br/>

Create `.github/workflows/snake.yml` in your `itsprathi/itsprathi` repo:

```yaml
name: generate snake animation
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch: {}
  push:
    branches: [ "main" ]

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - name: generate github-contribution-grid-snake.svg
        uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: push generated files to the "output" branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Commit it, run it once manually from the **Actions** tab, done — it re-runs nightly after that.

</details>

<details>
<summary><b>🔧 Set up Pac-Man (one-time)</b></summary>
<br/>

Easiest path: fork **jkdevcode/github-pacman**, rename it if you like, then:
1. In the fork's settings, create an `output` branch.
2. Enable GitHub Actions on the fork.
3. Edit the workflow to point at your username (`itsprathi`).
4. Run the workflow once from the **Actions** tab — it then re-runs every 12 hours.
5. Open the `output` branch and check the exact `.svg` filename it produced, then swap `PACMAN-FILENAME` above for that name.

*(If you'd rather run it inside `itsprathi/itsprathi` directly instead of a separate forked repo, the underlying engine is `abozanona/pacman-contribution-graph`, which also supports Breakout, Galaga, and a few other arcade skins on the same contribution grid — worth a look if plain Pac-Man gets boring.)*

### 🧱 3D Contribution Calendar

<div align="center">
<img alt="3D isometric contribution calendar" src="https://raw.githubusercontent.com/itsprathi/itsprathi/master/profile-3d-contrib/PROFILE-3D-FILENAME.svg" width="100%"/>
</div>

<details>
<summary><b>🔧 Set up the 3D calendar (one-time)</b></summary>
<br/>

Create `.github/workflows/profile-3d.yml` in `itsprathi/itsprathi`:

```yaml
name: GitHub-Profile-3D-Contrib
on:
  schedule:
    - cron: "0 18 * * *"
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    name: generate-github-profile-3d-contrib
    steps:
      - uses: actions/checkout@v4
      - uses: yoshi389111/github-profile-3d-contrib@0.7.0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          USERNAME: ${{ github.repository_owner }}
      - name: Commit & Push
        run: |
          git config user.name github-actions
          git config user.email github-actions@github.com
          git add -A .
          git commit -m "generated" || echo "nothing to commit"
          git push
```

It offers several style variants (night view, night-rainbow, season-based, "git block") — run it once, look in the new `profile-3d-contrib/` folder, and swap `PROFILE-3D-FILENAME` above for whichever variant you like best.

</details>

<summary><b>🔧 Connect Spotify (one-time, no API keys to type)</b></summary>
<br/>

**Now Playing card:**
1. Go to `https://spotify-github-profile.kittinanx.com`, click **Connect with Spotify**, and grant permission.
2. It gives you a `uid` — swap `YOUR_SPOTIFY_UID` above for it.

**Recently Played card:**
1. Go to the `JeffreyCA/spotify-recently-played-readme` Vercel app, click **Authorize**.
2. Swap `YOUR_SPOTIFY_USERNAME` above for your actual Spotify username.

Neither one requires you to register a Spotify Developer app or hand me any keys — it's a click-through OAuth grant on their hosted service. A true real-time "queue" widget isn't something either public tool exposes (Spotify's API doesn't make the play queue easy to read this way), so Now Playing + Recently Played is the honest ceiling here — self-hosting your own Spotify app would get you closer if you ever want that route.

</details>
